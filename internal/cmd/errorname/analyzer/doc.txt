checks that error variables begin with "Err"/"err" and error types end in "Error"

Sentinel errors (package-level variables) should start with Err, or err when unexported
(e.g., ErrNotFound). Structured error types should end with Error (e.g., ParseError).
See https://go.dev/wiki/Errors#naming.

With -fix, non-compliant declarations and their uses are renamed. Renamed exported
declarations keep their old name as a deprecated alias, so dependent packages continue
to compile. Generated names are a starting point; review them, e.g., with -fix -diff.

This check is also available as part of errortype (https://pkg.go.dev/fillmore-labs.com/errortype).

# Examples

To check the current package:

	errorname .

To fix error naming across packages:

	go fix -fixtool=$(which errorname) ./...
